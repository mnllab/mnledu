Redrawing a counseling-log table every single time

After a session wraps up, you open a word processor and start drawing a table. Make a date/location field, note the client, then write up the session and next steps. If you handle many clients, you repeat this from scratch every time.

This tool takes over that table-drawing step. Type directly into the form, or fill in multiple sessions' rows at once in a CSV template and drop it in — shared info like date, location, and client name stays the same across each record, while each session's own notes and next steps get filled in separately, and an A4 counseling log is generated. Check it in the live preview, then print it or save as DOCX/CSV.

What you enter never goes anywhere

Counseling notes often include sensitive personal details. This tool does all its processing inside your browser, and nothing you type is sent to or stored on a server. Close the page and your work disappears along with it.

What you can do

📝 Field-by-field entry
Enter date, location, client name, counselor, topic, hashtags, and author info, then write the body as two sections: Session Notes and Next Steps. Start a line with "-" for a sub-item, or with a circled number like "①②③" to mark it as a top-level category.
📋 Bulk CSV entry
Download the template, fill in rows for multiple sessions at once, and drop it in — you can then page through each record in the preview.
🔗 Automatic link detection
Any http(s) address typed into the body becomes a real, clickable link in both the preview and the DOCX export.
🖨️ Print and export
The A4-formatted view can be printed directly, and also exported as DOCX (single or bulk) or CSV.

How to use it

  1. Choose Manual Entry or CSV Upload on the left.
  2. Enter the session overview (date, location, client, counselor) and author information.
  3. Write the two body sections (Session Notes, Next Steps) one item per line. Use "-" for sub-items, or start with a circled number if you need a top-level category.
  4. Check the A4-formatted result immediately in the preview on the right.
  5. For multiple records, upload a CSV and page through them to review.
  6. When it's ready, print it or export as DOCX/CSV.

Frequently Asked Questions

Is the counseling content I enter sent to a server?
No. Everything is processed entirely in your browser, and closing the page clears your work along with it.
Can I create logs for multiple sessions at once?
Yes. Fill in one row per session in the CSV template and upload it — you can page through each one, and "Save All as DOCX" downloads them all together as a zip.
Does the formatting carry over into the DOCX export?
Yes — the info table, sub-item indentation, and links in the body all match the preview exactly.
Will the table break if I upload it to Google Docs?
No. The table uses fixed column widths, so the layout stays intact even in Google Docs.
What format should the date/time be in?
Pick it directly from the calendar widget, or use the "Now" button to fill in the current time instantly.
