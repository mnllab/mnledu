Markdown → Hangul (HWPX) Converter

Upload a Hangul (HWP) format file (hwpx) and only its defined styles and page setup are pulled in — the original text it contains is entirely discarded. Assign a style to each of your Markdown headings, body text, lists, quotes, and tables, and export everything, tables included, as an hwpx file. Files are processed entirely in your browser and never sent anywhere.

    Advanced Settings

    Line spacing, letter spacing, font size, and paragraph spacing all use the style's own values as-is. Anything not specified falls back to the body text style.

    If a list is mapped to a leveled style like Body 1/2/3, the marks above get added. If the style already assigns its own bullet or numbering, or if it's mapped to Body Text/Normal, no mark is added. Indentation always follows the style's own value.

    Only touch the line-count correction if characters overlap or blank lines are left over. Raise it if things overlap, lower it if there's too much gap.

        How to Use

        This tool is for keeping a Hangul (HWP) document's formatting exactly as-is, while writing just the content quickly in Markdown. Instead of setting up formatting again inside Hangul, it uses a document you're already using as the source of that formatting.

        • Take a report or plan you already use, and in Hangul do Save As → hwpx, then upload that file.
        • The tool reads the list of styles defined in that file, and you assign one to each of headings, body text, and lists.
        • Paste in your Markdown and export — an hwpx file comes out with your assigned styles applied.

        Supported Markdown Notation

        NotationResult
        # ~ ####Heading 1–4 style
        Plain lineBody text style (continues as one paragraph until a blank line)
        - item / * itemBullet paragraph, one level per 2-space indent
        1. itemParagraph with the number typed in as text
        > quoteBody text style (or the quote style, if the template has one)
        | table |Hangul table (first row is the header row; follows the template table's borders and character shape)
        [text](url)Only the text is kept (no hyperlink is inserted)

        Standardizing Your Template

        Write a line like "this notation is this style" directly in the body of your template file, and the next time you upload it, matching happens automatically and exactly. Since the style name is written out as plain text, this still works correctly even if that line accidentally has the wrong style applied to it (a typo or copy-paste slip) — it's found by name regardless.

        Sample LineMeaning
        # Heading: Outline1Heading 1 is the style named "Outline1"
        Body: BodyBody paragraphs use the style named "Body"
        - List: Body1List level 1 is "Body1"
          - List: Body2List level 2 is "Body2" (2 or more leading spaces)
        | table |: TableTextText inside tables uses "TableText"

        Things to Know

        • Hangul stores each line's on-screen coordinates inside the file itself. Since this tool recalculates those coordinates when writing, opening the exported file in Hangul once and saving it will fully tidy up the coordinates.
        • If characters look like they're overlapping, raise the line-count correction in Advanced Settings; if there's too much gap between lines, lower it.
        • The uploaded file is used for formatting only. All of its original body text is discarded — only the styles, paper settings, page margins, and header/footer remain.
        • If there are multiple sections, content goes into the first section and the rest are left empty.
        • Tables are placed inline with text and centered. Width never exceeds the body text width, with a default cap of 150mm. All columns are made the same width — adjust widths or merge cells afterward in Hangul.
        • Character-level shape settings like letter spacing and condensation are left untouched and simply follow whatever the assigned style specifies.
        • Footnotes, images, and hyperlinks are not inserted.
