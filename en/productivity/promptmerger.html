What goes wrong when you hand an AI several files

Uploading files one at a time blurs the line between them, and simply pasting them end to end removes it entirely. The model then answers about the wrong file, or merges two of them into a single confused explanation.

This tool labels each file and marks its boundary with a code fence or a rule, then joins them into one prompt. It also shows the total character count and a rough token estimate, so you can tell before you paste whether you are near the model's input limit.

When to use it

Code review across files
Asking about a feature that spans several modules. Clear file boundaries are what make the answer specific.
Summarising a set of documents
Handing over several meeting notes or reports and asking what they have in common.
Checking the size first
Seeing the token estimate before you paste. Over the limit, it is better to split the question in two than to have the input silently truncated.
Keeping a reference bundle
Saving a set of files as one text block so you do not have to gather them again next time.

How to use it

  1. Add your files. Several at once is fine.
  2. Choose whether to separate them with code fences or rules.
  3. Check the size, then use Copy the whole prompt and paste it into your AI tool.

Settings

Code fences
Wraps each file in triple backticks. The right choice for source code, since the model can tell code from commentary.
Rule separated
Divides files with a plain rule. Easier to read for ordinary documents.

Frequently asked questions

How accurate is the token estimate
It is approximate. Every model counts tokens differently, so leave some headroom when you are near a limit.
Are my files uploaded
No. Your browser reads them directly and joins them on screen. Nothing is transmitted.
Which file types work
Anything that reads as text: source files, txt, md, csv, json, yml and similar. Compressed formats such as Word documents or PDFs need converting to text first.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
