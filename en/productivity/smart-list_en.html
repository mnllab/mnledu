Getting a spreadsheet column into a To field

You drag down the email column in a spreadsheet and copy it. Paste that into the Outlook recipients field and the addresses stack up vertically, and pressing send gets you a complaint about the address format.

So you paste it into a text editor and replace the line breaks with semicolons by hand, or write a CONCATENATE formula. Past a hundred names, that is its own afternoon.

This tool removes the step. Paste, pick where it is going, and it comes out as one line.

Why the separator matters

Services do not agree on how to separate recipients. Outlook uses semicolons; Gmail uses commas. Get it backwards and the whole string reads as one malformed address.

📧 Outlook
a@a.com; b@b.com — semicolon and space.
✉️ Gmail
a@a.com, b@b.com — comma and space.
💬 Slack and messengers
@user1 @user2 — an @ in front, separated by spaces. Names that already carry one are left alone.
🗄️ SQL IN clause
'item1', 'item2' — wrapped in single quotes, with any quote inside the value doubled so the statement holds.
⚙️ Custom
Set the separator, a wrapper and a prefix yourself. Pipes, slashes, brackets — whatever the destination wants.

What gets tidied up first

Data copied out of a spreadsheet is rarely clean. A blank row in the middle, trailing spaces, the same address entered twice.

Blank lines and surrounding spaces are removed automatically. If you copied several columns at once, the tabs are split into separate items, and values that arrive wrapped in quotes have them stripped.

  • Remove duplicates — on by default, and it tells you how many went.
  • Ignore case — treats Kim@a.com and kim@a.com as the same entry.
  • Sort alphabetically — when you want the list in order.
  • Strip quotes — for when every value came across quoted.

How to use it

  1. Copy a column from your spreadsheet and paste it on the left.
  2. Pick where it is going. An example shows what the output will look like.
  3. Adjust the clean-up options if you need to. The result updates as you change things.
  4. Press Copy result and paste it where you need it. Clicking the result area copies too.

Frequently asked questions

Why does the separator differ by platform?
Outlook separates recipients with semicolons; Gmail uses commas. Paste the wrong one and the whole string reads as a single malformed address, and sending fails. Choose where you are pasting and the right character is applied for you.
Can I paste straight from a spreadsheet?
Yes. Blank lines and surrounding spaces are cleaned up automatically, and if you copied several columns the tabs are split into separate items. Values that come across wrapped in quotes have those quotes stripped as well.
Anything to watch for with SQL?
A single quote inside a value breaks the query. This tool doubles any it finds, so O'Brien comes out as 'O''Brien' and the statement stays valid.
How are duplicates handled?
With duplicate removal on, only the first occurrence of a value survives. Turn on ignore case as well to catch the same address written with different capitalisation. The count of what was removed is shown alongside the result.
Is anything I type sent anywhere?
No. Every conversion happens in your browser, so the tool works with the connection switched off. Internal addresses and customer lists stay on your machine.
Can I define my own format?
Choose Custom and you can set the separator, a character to wrap each item in, and a prefix to put in front. Pipes, slashes, brackets — whatever shape you need.

Every conversion runs inside your browser and nothing you type is transmitted to any server. Closing the page clears what you entered, so copy anything you need to keep. When mailing a large group, consider using BCC so recipients cannot see each other’s addresses.
