Paste your text and switch on whichever rules you need

This tool is a workspace for quickly tidying text that arrives in mixed formats: web copy, meeting notes, video scripts, spreadsheet lists. Your text is processed by JavaScript inside the browser only, with no external API calls and nothing sent to a server.

Paste the original on the left and combine whichever features you need in the middle. The result on the right recalculates the moment you type or change an option, so there is no run button to press.

The cleaning options can be combined

Strip markdown symbolsremoves the syntax for headings ( #), emphasis ( **), links ( [text](url)) and quote marks, leaving only readable prose. A link keeps its link text rather than its address.

Unbunch list itemslooks for 1., 2., -, • inside a run-on sentence and breaks a new line before it. Turning on the whitespace cleanup at the end also trims each line and collapses repeated blank lines.

Subtitle splitting keeps words whole

With subtitle mode on and a limit set between 10 and 40 characters per line, it breaks at a space wherever possible. A single long word is never cut in half and stays on one line.

Pair into two-line subtitlesTurning this on keeps a line break between the two lines of a subtitle pair and separates the next pair with a blank line, ready to paste straight into a subtitle editor.

List and spreadsheet processing works line by line

Choosing number or custom bullet prefixes every non-blank line. Removing duplicates keeps only lines that match exactly, so similar-but-different data stays untouched.

Extract only URLs / emailsTurning this on finds every web address and email in the current text and lists them one per line, useful for pulling out a mailing list or a set of reference links.

Frequently asked questions

Is my text sent anywhere?
No. Every rule and pattern runs in your current browser. There are no network requests, API calls or account logins.
Can it handle long text?
Yes. Even with very long input, processing is batched so it does not re-run on every single keystroke. Text running into the hundreds of thousands of characters may still take a moment depending on your browser and device.
Can I compare the original and the result side by side?
The left and right panels sync their scroll position proportionally, so you can compare the same relative point even when the result has a different number of lines.
Can I edit the result directly?
The result panel is read-only to prevent accidental overwrites. Copy what you need and finish editing it in your own document or editor.

All text processing in this app happens in your local browser. The Tailwind CSS CDN is used only to load visual styling; the text you enter is never processed, analysed or stored on a separate server.

Cleaning up text that arrives in mixed formats

Text copied from the web, meeting notes, video scripts and spreadsheet lists all carry their own habits: stray markdown symbols, list items bunched into one sentence, uneven blank lines.

This tool combines the cleanup rules you need. Paste the original on the left, switch on a rule, and the result appears on the right immediately.
