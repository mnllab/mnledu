“Send it out split by region”

One company-wide list arrives and has to become fifteen regional files, each saved separately, each attached to its own email. Filter, copy, paste into a new file. Fifteen times.

An hour’s work, and easy to get wrong — miss a region, or save with the filter still applied and ship the wrong rows to someone.

This does all of it once you pick the column to split on.

Three steps

  1. Load a file — drag in an Excel or CSV file. Choose the sheet if there is more than one.
  2. Pick the key column — region, department, whatever divides it. Choosing one tells you how many distinct values it holds first.
  3. Download — check the split and take the whole lot as one ZIP.

The preview table highlights the chosen column, so a wrong pick is obvious immediately.

No rows go missing

After splitting, the screen confirms whether the totals still match the original. Losing a handful of rows is the real danger when filtering by hand, and here you can see it did not happen.

Rows with a blank key are not discarded either — they collect into a (blank) file. Leading and trailing spaces are ignored, so Seoul and Seoul never split into two files.

Filenames that do not collide

Slashes and question marks cannot go in a filename, so they become underscores. That creates a trap: Sales/1 and Sales:1 both become Sales_1, and one would overwrite the other.

When that happens a number is appended instead. The file count always matches the group count.

Tens of thousands of rows

Files are built one group at a time so the page never locks up. A progress bar moves as it goes, so you can tell it is working rather than hung.

Compression comes after. Since the files share a structure, it compresses well — 3.5MB down to 0.4MB in testing.

If the data is confidential

Your file is never uploaded. Reading, splitting and zipping all finish inside this browser.

To be certain, open the page and then disconnect from the internet — it still works. Once the interface has loaded, nothing further is exchanged with the outside.

Frequently asked questions

Are my files uploaded?
No. Reading, splitting and zipping all happen inside your browser, and the tool works with the connection switched off. For confidential material, open the page first and then disconnect — it will still work.
How many rows can it handle?
Tens of thousands are fine. Files are built one group at a time so the page never freezes, which takes a moment longer but shows you progress as it goes.
What happens to blank values in the key column?
They are grouped together into one file rather than discarded, so every row from the original ends up somewhere. The screen confirms whether the totals still match after splitting.
What about characters filenames cannot use?
Slashes, question marks and the like are replaced with underscores. If two values collide after that substitution, a number is appended so no file overwrites another.
Does it work with multi-sheet workbooks?
If there is more than one sheet you can choose which to use, and only that sheet is split. The first row is treated as the column names.
Can I get CSV instead?
Yes, pick CSV instead of Excel. The CSV files carry a byte-order mark so non-Latin characters open correctly in Excel.

Everything runs inside your browser and the file you load is never sent to any server. Closing the page clears what was read. Browser memory has limits, though, so very large files or splits producing hundreds of groups are better handled in batches.
