When the data arrives in a different shape every time

One list comes out of a spreadsheet, another is a bracketed block from a document, a third is a markdown table. The sentence you want to produce is identical each time, but the input shape keeps changing, so you end up reformatting by hand before you can start.

This tool accepts all three. Paste whatever you have, write the sentence pattern once, and every row is filled in at the same time.

When to use it

Letters to many recipients
The same notice going to different organisations, with only the name and contact changing.
Review comments
Documents where the headings are fixed and only the content varies. Faster to set the pattern and pour data into it.
Product descriptions in bulk
Catalogue copy where the structure is identical and only the model and specification change.
Generating SQL or config lines
Repeated code where only the values differ. Write one line with fields and get the whole set.

How to use it

  1. Paste your data. A bracketed list, a spreadsheet range or a markdown table all work.
  2. Write the sentence pattern. Click a field chip or type {FieldName} directly.
  3. The results build as you type. Use Copy all results to take them away.

Settings

Input mode
Tell the tool which shape your data is in. With a spreadsheet or markdown table the first row becomes the field names.
Result separator
Separate entries with a blank line, a plain line break or a horizontal rule. Blank lines suit documents, line breaks suit code.
Copy format
Plain text or a version that keeps formatting when pasted into a word processor.

Frequently asked questions

Do I have to reformat my data first
No. Bracketed lists, spreadsheet ranges and markdown tables are all recognised. If the first row holds the column names, those become your fields.
How is this different from the bulk email generator
The email tool is built around a subject and body and handles Korean grammatical particles. This one is a general purpose text generator that does not care what shape your data arrives in.
Can I load a file instead of pasting
Yes. Drop a txt, csv, tsv or md file onto the data area. It is read in your browser and never uploaded.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
