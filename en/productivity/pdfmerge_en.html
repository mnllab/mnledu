Combining PDFs without installing anything

Applications usually want several supporting documents bundled into a single PDF. The reverse happens too: a long report where only a few pages need to go to someone else.

The usual answers are a paid desktop application or an unfamiliar website that wants you to upload the file. That second option is worth pausing over, because these documents tend to be exactly the ones you would not want to hand over: bank details, registration certificates, signed contracts. This tool runs in your browser, so the file never leaves your machine.

When to use it

Bundling application documents
Combining a registration certificate, bank details and other evidence into one submission file.
Pulling out a few pages
Sending one chapter of a long report rather than the whole thing.
Fixing duplex scans
When a double sided scan came out as separate odd and even files, the odd and even buttons sort it out.
Splitting for email
Halving a PDF that is over an attachment size limit.

How to use it

  1. Choose Merge or Extract.
  2. Drop your files in, or click to select them. For merging, drag the rows to set the order.
  3. For extraction, type the page range, for example 1-3, 5, 7-10.
  4. Press the download button.

Settings

All, odd and even pages
One click shortcuts for common ranges. The odd and even buttons are what you want for a duplex scan that came out in two files.
First half and second half
Splits the document down the middle, usually because of an attachment size limit.
Save each range as a separate file
With several ranges entered, choose whether to get one combined file or one file per range.

Frequently asked questions

Where do my files go
Nowhere. Your browser reads the file, does the work and hands you the result directly. Nothing is uploaded, which is the point when the document contains sensitive material.
Do password protected PDFs work
No. A file with an open password cannot be processed. Remove the password first.
How do I write a page range
Separate entries with commas and use a hyphen for a span. So 1-3, 5, 7-10 means pages 1, 2, 3, 5, 7, 8, 9 and 10.
Is there a file size limit
No fixed limit, since there is no upload. Very large files depend on the memory available to your browser.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
