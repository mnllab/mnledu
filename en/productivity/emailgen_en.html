When the same email has to go out twenty times

Twenty recipients, the same message, but each one needs their own name, company and meeting time. Mail merge means installing something and wiring up a data source. Doing it by hand means twenty rounds of find and replace, and a real chance that message fourteen still says someone else's name.

This tool sits in the middle. Write the message once with fields in curly braces, paste your list straight out of a spreadsheet, and every message is built at once. Empty fields are removed along with the spacing around them, so a missing value never leaves a dangling comma or an empty line.

When to use it

Event and meeting invitations
Paste a spreadsheet of attendees and get one message per person, each with their own time and location.
Review and application outcomes
The wording is fixed and only the company and contact change. A typical merge, and a bad place for a copy and paste mistake.
Scheduling across a list
Send everyone the same instructions with a different slot in each message.
Recurring client notices
Price changes, holiday hours, anything that goes out regularly. Save the template and it is ready next time.

How to use it

  1. Write your subject and body in Template. Mark anything that changes as {Company} or similar.
  2. Paste your list into the data box. Copying a range out of a spreadsheet keeps the tab separation, so it just works.
  3. Check the preview, then use Copy message for one at a time or Bulk for the whole set.
  4. Send them from your own mail client.

Settings

Single and Bulk
Single builds one message from values you type in. Bulk runs the template over every row of your list and shows all the results together.
Plain text and Markdown
Plain text suits an ordinary mail client or a web form. Markdown keeps the bold and list formatting for Slack, Notion and similar tools.
Saved templates
Give a template a name and it stays in your browser for next time. It is stored on your device rather than on a server, so clearing browser data clears it.

Frequently asked questions

Can I paste directly from a spreadsheet
Yes. Copying a range gives tab separated text, which is read as columns automatically. Comma separated data works too.
What happens if a value is missing
The field is removed along with the surrounding spacing, so you do not end up with a stray comma or a blank line. The count of empty fields is shown above the preview.
Does it send the emails
No. It only builds the text. Sending happens in your own mail client, which keeps your contacts and credentials out of this page entirely.
Is my recipient list uploaded anywhere
No. The list stays in your browser and is never transmitted. That matters, because a recipient list is personal data.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
