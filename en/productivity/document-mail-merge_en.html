How to use

  1. Mark each replaceable value as {{Name}}, {{Company}}, or {{Date}}. Reusing the same field counts as one field, and you can use up to 20 unique fields.
  2. You can type a template directly or load a TXT, Markdown, DOCX, or HWPX file. DOCX and HWPX files are read inside the browser so their merge fields can be detected.
  3. For a single document, enter values in the automatically generated field inputs. The preview updates immediately.
  4. For batch output, choose an Excel/CSV file or drag it into the batch-data area. The first row is treated as field names, the second row is shown as the preview sample, and Export generates every row from row 2 onward into one ZIP file.
  5. Excel/CSV column names must exactly match the template fields. For example, {{Name}} connects to a first-row column named Name.
  6. You can also use fields in the file-name pattern. {{Number}} is a reserved field that automatically increments as 001, 002, 003, and so on.

Supported formats and formatting

Output formats are HWPX, DOCX, TXT, and MD. For templates typed directly or converted to a different format, the selected font size, line spacing, paragraph spacing, and alignment are applied to newly generated HWPX/DOCX files. When a DOCX or HWPX template is exported to the same format, the original document formatting takes priority. TXT and MD preserve the text structure. In Excel/CSV batch mode, one document is generated for each data row and the results are bundled into a ZIP file.

Preserving original DOCX/HWPX formatting

When you load a DOCX or HWPX template, the preview shows plain text for content verification only. When you export back to the same format, the tool does not rebuild the document. Instead, it clones the original package and replaces only the text inside {{fields}}. This preserves the original fonts, font sizes, colors, paragraph formatting, tables, images, headers, footers, and other document objects. A DOCX template preserves its formatting when exported as DOCX, and an HWPX template preserves its formatting when exported as HWPX. Converting to a different format creates a new document using the common formatting options above.

If you directly edit the extracted template text after loading a DOCX/HWPX file, formatting-preservation mode is automatically disabled because the screen text may no longer match the original document structure. Entering values for existing {{fields}} or connecting Excel/CSV data does not disable preservation mode.

Is my data sent to a server?

No. Template reading, Excel/CSV parsing, field replacement, DOCX/HWPX generation, and ZIP packaging all happen inside the current browser tab. Closing or refreshing the page clears the working data.

Note: The legacy Word binary format .doc is not supported. Save it as .docx in Word or Google Docs before loading it. Excel batch data uses the first worksheet.

A hundred copies of the same letter, only the name different

Invitations, notices, contracts — sometimes you need many copies of the same document where only the name, date or amount changes. Copy-pasting each one by hand is exactly how a detail slips through.

This tool finds {{name}}, {{date}} and similar fields in a document automatically, then generates one document per row of an Excel or CSV file and zips them up — keeping the original formatting for DOCX and HWPX.

When to use it

Sending invitations at scale
Turning one guest list spreadsheet into dozens of invitations, each with the right name, in one pass.
Bulk contracts and confirmations
Producing contracts that differ only by client name or amount, keeping the original document's formatting.
Preserving DOCX/HWPX formatting
Keeping a template's fonts, tables and headers exactly as they are while only the content changes.
Exporting to whichever format you need
Using the same template to produce HWPX, DOCX, TXT or Markdown.

How to use it

  1. Type a template directly, or load a TXT, MD, DOCX or HWPX file.
  2. Mark the fields that should change, like {{name}} or {{date}} (up to 20 unique fields).
  3. For one document, fill the fields directly. For many, load an Excel or CSV file and export.

Frequently asked questions

Is my data sent to a server
No. Reading the template, parsing Excel/CSV, substituting fields, building the documents and zipping them all happens inside your browser.
Do Excel column names need to match the template fields exactly
Yes. A template field like {{name}} needs to match a column named exactly "name" in the first row of your spreadsheet to connect correctly.
If I export a DOCX file as HWPX, is the formatting preserved
No. Original-formatting preservation only applies when exporting to the same format (DOCX→DOCX, HWPX→HWPX). Converting to a different format generates a fresh document using the common formatting settings on screen.
