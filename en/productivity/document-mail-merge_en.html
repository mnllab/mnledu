A hundred copies of the same letter, only the name different

Invitations, notices, contracts — sometimes you need many copies of the same document where only the name, date or amount changes. Copy-pasting each one by hand is exactly how a detail slips through.

This tool finds {{name}}, {{date}} and similar fields in a document automatically, then generates one document per row of an Excel or CSV file — as separate files in a ZIP, or combined into a single document — keeping the original formatting for DOCX and HWPX. For Korean templates, it can also auto-correct grammatical particles (은/는, 이/가) to match whatever value gets substituted in.

When to use it

Sending invitations at scale
Turning one guest list spreadsheet into dozens of invitations, each with the right name, in one pass.
Bulk contracts and confirmations
Producing contracts that differ only by client name or amount, keeping the original document's formatting.
Preserving DOCX/HWPX formatting
Keeping a template's fonts, tables and headers exactly as they are while only the content changes.
Working from a shared company template
Picking a pre-registered DOCX or HWPX template from a list instead of uploading a file each time.

How to use it

  1. Type a template directly, load a TXT, MD, DOCX or HWPX file, or pick one from the company template list if one is set up.
  2. Mark the fields that should change, like {{name}} or {{date}} (up to 20 unique fields).
  3. For one document, fill the fields directly. For many, load an Excel or CSV file, choose separate files or one combined file, and export.

Settings

Keep original DOCX/HWPX formatting
Exporting a DOCX template to DOCX (or HWPX to HWPX) keeps the original fonts, tables, images and headers intact. Editing the template text directly turns this off automatically.
Korean particle auto-correction
When a field in a Korean template is followed by a particle like 은 or 이, it is swapped for 는 or 가 automatically based on whether the substituted value ends in a consonant. Only genuinely ambiguous cases (e.g. values ending in a digit) prompt a review.
Combine into one file
Available for DOCX and HWPX exports. Instead of a ZIP of separate files, every generated copy is placed one after another in a single document.
Lightweight AI assistant
Optionally matches spreadsheet columns to template fields even when the names differ, and checks the result for empty fields, leftover tags, and malformed emails or URLs — all inside the browser.

Frequently asked questions

Does it handle Korean particles like 은/는 automatically
Yes. If a template field is followed by a Korean particle — {{name}}은, {{company}}이 — the correct form is chosen automatically based on whether the substituted value ends in a consonant. You only get asked to confirm when the ending genuinely can't be determined, such as a value ending in a digit. This can be turned off entirely.
What does the lightweight AI assistant do
Two things when turned on: AI matching connects a spreadsheet column to a template field even when the names don't match exactly (like {{contact_name}} and "contact"), and a final check flags empty fields, leftover tags, malformed emails or URLs, and gaps in batch mapping. Both run inside your browser — only field values and column-mapping information are involved.
What is a company template
If a set of templates has been registered for this site, you can pick one directly on screen instead of uploading a file. It reads the body text and {{fields}} exactly as if you'd chosen the file yourself. This section doesn't appear if no templates are registered.
Can I get every document combined into one file
Yes. When exporting to DOCX or HWPX, choose "Combine into one file" to merge every generated copy into a single document. Other formats, or the default choice, still produce one file per row zipped together.
Is my data sent to a server
No. Reading the template, parsing Excel/CSV, substituting fields, building the documents and zipping them all happens inside your browser.
If I export a DOCX file as HWPX, is the formatting preserved
No. Original-formatting preservation only applies when exporting to the same format (DOCX→DOCX, HWPX→HWPX). Converting to a different format generates a fresh document using the common formatting settings on screen.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
