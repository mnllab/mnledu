Hunting down the same things over and over

What was the company red again? You go digging through the brand guide. You need the signature image, so you trawl through folders. The email sign-off comes from copying an old message.

Each is a thirty-second job that comes round several times a day. This puts all of it in one place, one click from the clipboard.

Click to copy, that is the whole thing

Click a card and it lands on your clipboard. No opening an editor, no dragging to select.

  • 📝 Text — copies the phrase as it is. Good for sign-offs, hashtag sets, standard replies.
  • 🎨 Colours — copies the six-digit form, with the rgb value shown on the card.
  • 🖼️ Images — the image itself goes on the clipboard. Paste straight into a document or a deck.
  • 🔗 Links — copies the address; the arrow opens it in a new tab.

Why the images actually paste

Usually copying an image gives you a file path or a URL. Here the image data itself goes onto the clipboard, which is why it drops into a slide without a detour through the file system.

In practice PNG is the only format that gets accepted, so whatever you load is converted to PNG on the way in. If your browser blocks the feature, the file is downloaded instead.

Images are stored separately

Keeping text and images together fills up fast — browsers give text roughly 5MB, which a couple of photos will exhaust.

So images go into a much larger store of their own. Dozens of logos or signatures are no trouble. Large photos are scaled to 1200 pixels on the long edge, so the size stays reasonable.

When you change browsers

Everything lives in this browser. It will not show up on another machine, and clearing browser storage removes it.

Backup downloads a single file with the images included, and restore brings it all back in a new browser. Worth taking one occasionally if you keep anything you would miss.

Made to sit beside your work

The cards reflow as the window narrows, so it parks happily alongside whatever you are working in. There is a dark mode too.

Once you have a lot of items, use the search box at the top — it filters on names and contents.

Frequently asked questions

Is anything I save uploaded?
No. Everything including images stays inside this browser, and the tool works with the connection switched off. It will not appear on another device, so use the backup file to move things across.
Do images really paste into documents?
Yes. The image itself goes onto the clipboard, so it pastes straight into documents, slides or an image editor. If your browser blocks that or is too old, it downloads the file instead.
How many images can I store?
They are kept in a much larger store than the text, so dozens of logos or signatures are fine. Large photos are scaled to 1200 pixels on the long edge, which keeps the size down.
What if I switch browsers?
Download a backup file and restore it in the new browser — images come across too. Clearing browser storage wipes everything, so it is worth taking a backup now and then.
What colour formats are accepted?
Six digits or three, with or without the hash. Pasting an rgb value works as well and gets converted. Clicking copies the six-digit form by default, and the rgb value is shown on the card.
Is there a search?
Type in the box at the top and it filters on both names and contents. Once you have a lot of items that beats switching between tabs.

Everything runs inside your browser and nothing you save is sent to any server. It uses this browser\u2019s storage, so it does not appear on other devices and disappears if that storage is cleared or you work in a private window. Think twice before storing anything sensitive on a shared machine, and keep a backup file of anything you would miss.
