A QR code that will not expire

Plenty of sites will make you a QR code, but many of them route it through a short link on their own servers. When that service shuts down or the free tier lapses, every code you printed dies with it.

This tool encodes what you type straight into the pattern. There is nothing in the middle — no expiry, no scan tracking, no account. Print it once and it keeps working.

How to use it

  1. Enter a URL or any text. Phone numbers and Wi-Fi details work too, not just links.
  2. Set the size. For anything printed, 1000px or larger is a safe floor.
  3. Adjust the colours if you want, or drop the background entirely.
  4. Press Generate QR code, or just hit Enter in the text field.
  5. Download as PNG or SVG.

Making sure it scans

Keep the contrast strong
The code must be darker than its background, and the greater the difference the better it reads. The page warns you when contrast falls short.
Leave the margin alone
The blank band around the code is what a scanner uses to find its edges. Keep it at 4 or above for print.
Print it large
Longer content means a denser pattern. The module count shown on screen tells you how fine it is — the higher that number, the bigger you should print.
High resilience
Leave this on and the code still reads when part of it is smudged, covered or roughly printed. Worth keeping for labels and stickers.

Frequently asked questions

Do the codes expire or have a scan limit?
No. What you type is encoded directly into the pattern, so there is no redirect service in the middle — nothing to expire, nothing tracking scans. A code you print today keeps working indefinitely.
Does it work without an internet connection?
Yes. Everything needed is contained in the page itself, so it opens and works with no connection at all. Save the file and it will run on an air-gapped machine or behind a corporate firewall.
Should I download the PNG or the SVG?
PNG suits screens and documents; SVG suits print and signage. Because SVG is vector, it stays perfectly sharp no matter how large you scale it.
When would I use a transparent background?
When placing the code over a coloured panel or a photograph. Keep in mind that scanning gets harder on dark or busy backdrops, so place it over a light area or pick a code colour with strong contrast against whatever sits behind it.
Why does the code need a margin?
That empty band is what a scanner uses to find the edges of the code. With too little of it the pattern blends into whatever surrounds it, so keep the margin at 4 or above for anything printed.

This tool runs entirely inside your browser. Nothing you enter is transmitted or stored anywhere. Before printing or distributing, scan the finished code with a real device to confirm it reads correctly.
