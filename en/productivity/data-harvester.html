Three small office chores that keep coming back

They look unrelated but they turn up in the same afternoon. A list of deliverables has to be typed out, links have to be picked out of an email thread, and a URL someone pasted has arrived as unreadable gibberish.

None of it is hard. All of it is tedious. Thirty files means typing thirty names, links get hunted down and copied one by one, and an encoded address gives you nothing to work with.

These three sit together here. Switch tabs and use whichever you need.

📁 File list

For deliverable lists and submission indexes. Drop files in and it lays out name, type, size and modified date as a table.

Folders work too. Drop one and it walks through the nested subfolders, finds everything inside, and notes the path each file came from.

The important part: nothing is uploaded. The browser reads names and sizes; it never opens the contents. Confidential material can go in without leaving your machine.

Copy for spreadsheet puts tabs between the cells, so pasting into Excel or Sheets drops every value into its own cell.

🔗 Links and emails

For long email threads and meeting notes where the addresses are scattered through the text. Paste the whole thing and links and email addresses come back as two separate lists.

A few awkward cases are handled:

  • Sentence punctuation is trimmed. In http://a.com/b. the final stop is not part of the address.
  • Brackets are counted in pairs. Where they belong to the URL, as in many Wikipedia links, they stay.
  • Repeats collapse to one. Addresses differing only in capitalisation count as the same.
  • Emails inside URLs are skipped so a string in a link is not mistaken for an address.

The collected addresses can be copied in Outlook format, ready to paste into a recipients field.

🌐 URL decoder

Addresses can only carry a limited set of characters, so anything else is rewritten as %EC%95%88%EB%85%95-style codes. The address bar shows it back as text, but copy it out and the codes come with it.

This tab reverses that. It decodes as you paste, and clicking the result copies it.

  • Doubly encoded addresses are unwound automatically.
  • Broken fragments do not stop it — the readable parts are converted and you are told about the rest.
  • It goes the other way too, for when you need to encode an address instead.

Frequently asked questions

Are the files I drop in uploaded?
No. The browser reads only each file’s name, size and modified date to build the table; the contents are never opened. The tool works with the connection switched off.
Can I drop a whole folder?
Yes. Drop a folder and it walks through everything inside, following nested subfolders however deep they go, and records the path each file came from.
What happens to the full stop after a link?
Sentence punctuation and closing brackets are trimmed off the end of a URL. Where brackets are genuinely part of the address, as in many Wikipedia links, the pairs are counted and kept. Repeated addresses are collapsed into one.
Why do URLs turn into percent codes?
Addresses can only carry a limited set of characters, so anything outside that set is rewritten as percent-prefixed codes. This tool reverses the process to show the original text, and it unwinds addresses that were encoded more than once.
How do I move the list into a spreadsheet?
Copy for spreadsheet puts the table on your clipboard with tabs between the cells. Paste it into Excel or Sheets and every value lands in its own cell. Use the CSV download to keep it as a file instead.
Opening all links sometimes gets blocked
Browsers treat several windows opening at once as pop-ups. Allow pop-ups for this site from the prompt in the address bar and they will open. With a long list it is safer to open them in batches.

Everything runs inside your browser and neither your files nor anything you type is transmitted to a server. The file list reads only metadata such as names and sizes; file contents are never opened. Closing the page clears the work, so copy or download anything you need to keep.
