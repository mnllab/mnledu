For when the conversation stalls


An awkward silence lands at dinner, or mid-stream you run out of things to say and the chat has gone quiet. One good either-or question buys you ten minutes.


The trouble is that good ones are hard to invent on the spot. This deals them out, and lets you add your own or generate a batch when the built-in set runs thin.



Questions do not repeat


Straight random picking brings back the question you just saw. With five in the pool it happens roughly one time in five.


So a question will not return until the whole set has been through. When the set reshuffles, the previous question is moved out of first place so it cannot come round twice in a row. The count of what is left shows below the arena.



Built for the big screen


Options vary wildly in length, so fixed type either overflows or looks lost. Here the type scales to the character count — short lines come out very large and read from across the room.


Stage mode strips away everything except the two options and fills the display. Drop it straight into a broadcast layout.


The keyboard works too: arrows to choose, space for the next question. No hunting for the mouse.



Choosing lands with a bang


Click an option and the screen shakes with a white flash. The winner grows with a neon glow while the loser shrinks away in greyscale.


It is not subtle, but the moment of choice has to be visible for anyone watching to react to it.



Two ways to add more


➕ Write your own
Enter A, B and a category. Duplicates are caught and flagged.


🤖 Generate with AI
The button gives you a prompt to copy. Paste it into a chatbot and paste the reply back here.




The import is deliberately forgiving. Wrapped in ```json, prefixed with const questions =, keys without quotes — all of it gets read. Duplicates are filtered and you are told how many landed.



Managing what you added


Your own questions can be deleted individually under Manage, or exported to a file. They live in this browser only, so export anything you would rather not lose.



Frequently asked questions


Will the same question keep coming up?
Once a question has appeared it will not return until the whole set has been through. When the set reshuffles, the previous question is moved so it cannot immediately repeat either.


How do I add questions generated by AI?
The button at the top gives you a prompt to copy. Paste it into a chatbot, then paste the reply back into this page. Code fences, variable declarations and unquoted keys are all handled.


Where are my own questions stored?
In this browser only, and they survive closing the tab. They will not appear on another device and are lost if you clear browser storage, so export anything you would miss.


Does it work on a big screen?
That is what it was built for. Type scales to the length of each option, so short lines come out very large. The stage button strips away everything else and fills the screen.


Can I use the keyboard?
Left and right arrows choose, space deals the next question, and 1 and 2 work too. No reaching for the mouse mid-stream.


Is my choice recorded?
The side you picked is highlighted, and copying the current question includes which one you chose. It is not a running log, though, so copy anything you want to keep as you go.





Everything runs inside your browser and questions you add are never sent to any server. They use this browser\u2019s storage, so they do not appear on other devices and disappear if that storage is cleared. Read anything an AI generates before putting it on screen, and drop anything that could land badly with a particular person or group.
