R E S U L T

Adding a few seconds of suspense to a draw

Pull a name out of a hat and you get the result with nothing around it. Run it as a race and there are a few seconds of watching, which in a group is where the fun actually is.

Each participant gets a horse. The finishing order is random, and the result can be copied out as text to share.

When to use it

Deciding an order
Presentation order, or who goes first at anything.
Splitting a bill
Weighted odds, top three only, or winner takes all.
Running a group session
A short piece of theatre to lift the mood.

How to use it

  1. Name the horses, or draw random numbers for them.
  2. Add participants and which horse each is backing, with stakes.
  3. Choose a payout method and start the race.
  4. Copy the result to share it.

Settings

Weighted odds
Splits by finishing position at 3 : 2 : 1.4 : 0.6, so a poor finish still returns something.
Top three only
Only the first three positions pay out.
Winner takes all
Everything goes to whoever backed the winner.
Even
Sets every stake to the same amount in one click.

Frequently asked questions

Is the race fixed
No, the finishing order is random. The order you enter the horses makes no difference.
Can I use this for actual gambling
It is built for settling an order or splitting a bill among friends. Please treat it as entertainment.
How many people can play
Up to 20 participants and 10 horses.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
