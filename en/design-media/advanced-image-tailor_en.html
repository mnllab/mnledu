Fine-tune one image, then apply the same settings to all

This tool is a browser-based workspace for preparing several images to the same specification. Pick one from the list below to check it on the central canvas, then set the width, height, fit mode and anchor. Adjust the anchor and the same settings apply to every uploaded image.

Reading the original image, previewing it, cropping on canvas and building the ZIP all happen in the current browser. Uploaded photos are never sent to a separate server.

Set a size quickly, then unlock it if you need to

Choosing 16:9, 9:16, 4:3, 1:1 or Original sets the canvas to a commonly used ratio right away. Lock ratio on, changing one of width or height recalculates the other automatically.

Unlock it to enter both numbers independently, useful when a banner, thumbnail or ad creative needs an exact pixel size.

Set the fit mode and the 9-point anchor together

CropCover fills the target size completely and crops whatever overflows. Fit Width and Fit HeightFit width and Fit height each prioritise one dimension. PadContain never crops the original and fills empty space with the padding colour. StretchStretch ignores the original ratio and scales exactly to the size you set.

The anchor decides which side gets cropped or where the padding sits. If your subject sits in the upper left, choose the upper-left anchor; for a centred subject, choose the centre. The translucent part of the Crop preview shows the part of the original that will not survive into the final file.

Export and batch ZIP

Once the current photo looks right, Download current imagecheck it with Download current image. Once the settings are locked in, Download all as ZIPpress Download all as ZIP. Every photo in the queue is rendered in order with the same canvas size and fit mode, then saved as one ZIP file.

JPG lets you adjust the quality slider; PNG suits transparency or sharp graphics. Choosing PNG in Pad mode still fills the padding with your chosen background colour.

Frequently asked questions

Where does my photo go once uploaded?
It is read and rendered on canvas entirely inside your current browser. There is no server upload or account storage.
How do I know what gets cropped in Crop mode?
The sharp rectangle in the centre is the final output area. Whatever appears faded outside it is excluded from the exported file. Changing the anchor immediately shows what stays.
Can it handle a lot of images?
Yes. The ZIP is built by rendering one image at a time to keep memory use down. A large batch of very high-resolution originals may still take a while depending on your device.
The ZIP download does not start
Check your download-blocking settings, and briefly disable any extension that blocks script CDNs. JSZip and FileSaver are used to build and save the ZIP.

File content is processed entirely inside your browser. The JSZip and FileSaver CDNs are only used to load the JavaScript libraries that build and save the ZIP; they do not analyse or transmit the images themselves.

Preparing several photos to the same size

Banners, thumbnails and product pages often call for an exact pixel size. One image is easy in an editor, but twenty means cropping and saving the same way twenty times.

This tool takes the size, fit mode and anchor you set on one image and applies them to the rest of the batch, then hands back a single ZIP.

When to use it

Matching thumbnail sizes
Fitting images to the fixed ratio a platform like YouTube or a blog expects, all at once.
Uniform product photos
Cropping shop listing photos to the same size and padding so they line up neatly.
Several ad sizes from one photo
Exporting the same image as square, landscape and portrait for different channels in one pass.
Keeping faces in frame
Setting the anchor to where the subject sits so cropping never cuts off a face across a whole batch.

How to use it

  1. Upload several images.
  2. Set the size, fit mode and an anchor if needed.
  3. Check the result on one image, then download the whole batch as a ZIP.
