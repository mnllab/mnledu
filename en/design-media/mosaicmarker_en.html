When a screenshot has something in it that should not be shared

Captures pick up names, account numbers and email addresses along with whatever you actually meant to show. Opening an image editor to cover them is a chore, and uploading the file to an online editor means handing over precisely the thing you were trying to hide.

This pixelates and highlights inside your browser. The image never goes anywhere, which is the point when the thing you are covering is the sensitive part.

When to use it

Hiding personal details
Names, phone numbers and account numbers caught in a capture.
Support requests
Sending a screenshot of a problem without the unrelated information around it.
Drawing attention
Highlighting the part of the screen you are actually talking about.
Teaching material
Using a real screen as an example with the identifying parts removed.

How to use it

  1. Paste or drop in an image.
  2. Choose Pixelate or Highlight.
  3. Drag across the area you want to treat.
  4. Use Copy image to take it away.

Settings

Coarseness
The size of the pixelation blocks. Set it coarse when the point is to make text genuinely unreadable.
Colour
The highlighter colour.
Undo and reset
Undo the last stroke, or go back to the untouched original. Ctrl+Z works too.

Frequently asked questions

Can pixelation be reversed
The original pixels are gone from the exported image, so it cannot be undone. That said, very fine pixelation can leave shapes guessable, so use a coarse setting for anything that matters.
Is my image uploaded
No. Everything happens inside your browser.
Does the highlighter cover the text
No, it is semi-transparent so the text underneath stays readable. Use pixelation when the goal is to hide something.

This tool runs entirely inside your browser. Nothing you enter is sent to a server or stored anywhere, and closing the page discards the working data.
