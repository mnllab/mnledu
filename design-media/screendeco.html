캡처 화면이 자료에서 초라해 보이는 이유

화면을 캡처해 발표 자료에 넣으면 어딘가 엉성해 보입니다. 흰 배경에 흰 캡처가 붙어 경계가 사라지거나, 잘린 가장자리가 그대로 드러나기 때문입니다.

테두리를 다듬고 여백과 그림자를 주는 것만으로 인상이 달라집니다. 이 도구는 그 처리를 몇 번의 클릭으로 합니다. 맥 창 헤더를 씌우면 실제 프로그램 화면처럼 보이게 할 수도 있습니다.

이럴 때 씁니다

발표 자료 스크린샷
제품 화면이나 시연 장면을 슬라이드에 넣을 때.
블로그·SNS 이미지
글에 넣을 캡처를 다듬어 시각적으로 정돈할 때.
제안서·사업계획서
개발 중인 화면을 자료에 넣을 때. 배경과 그림자가 있으면 완성도 있어 보입니다.
매뉴얼·안내 문서
설명용 화면 캡처를 일관된 형식으로 맞출 때.

사용 방법

  1. 이미지를 넣습니다.
  2. 배경색, 여백, 모서리, 그림자를 조절합니다.
  3. 필요하면 맥 창 헤더를 켭니다.
  4. 이미지로 복사해서 바로 붙여넣습니다.

옵션 설명

배경색
캡처 뒤에 깔 색을 정합니다. 자료의 배경과 대비되는 색을 쓰면 경계가 살아납니다.
여백 · 모서리 · 그림자
여백은 답답함을 줄이고, 둥근 모서리와 그림자는 화면이 떠 있는 느낌을 줍니다. 과하면 산만해지니 적당히 잡는 편이 낫습니다.
맥 창 헤더 · 신호등
위쪽에 창 제목 표시줄을 붙입니다. 소프트웨어 화면을 소개할 때 씁니다.

자주 묻는 질문

이미지가 서버로 올라가나요
아닙니다. 브라우저 안에서 처리됩니다.
결과를 파일로 저장할 수 있나요
이미지로 복사한 뒤 문서에 바로 붙여넣는 방식이 기본입니다. 파일로 남기려면 붙여넣은 뒤 해당 프로그램에서 저장하시면 됩니다.
해상도가 떨어지지 않나요
원본 크기를 유지한 채 여백과 배경을 더하는 방식이라 화질 손실은 크지 않습니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
