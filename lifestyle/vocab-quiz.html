외우는 것과 아는 것의 차이

단어장을 눈으로 여러 번 읽으면 아는 것 같은 느낌이 듭니다. 그런데 막상 뜻을 떠올리려 하면 안 나옵니다. 읽어서 익숙해진 것과 꺼내 쓸 수 있는 것은 다릅니다.

기억을 붙잡는 데는 스스로 답을 꺼내 보는 과정이 필요합니다. 이 도구는 직접 만든 단어장을 카드로 뒤집어 보거나 객관식 문제로 풀 수 있게 합니다. 단어에서 뜻으로, 뜻에서 단어로 양방향 모두 연습할 수 있습니다.

이럴 때 씁니다

시험 대비 단어 암기
어학 시험이나 자격시험의 용어를 외울 때.
전문 용어 익히기
새 분야를 시작할 때 필요한 용어를 정리해 반복할 때.
수업·강의 복습
수업에서 나온 핵심 개념을 문답 형태로 만들어 확인할 때.
자녀 학습 보조
교과서 단어를 넣어 함께 풀어볼 때. 글자 크기를 키울 수 있습니다.

사용 방법

  1. 단어장 칸에 단어 / 뜻 형식으로 한 줄에 하나씩 적습니다.
  2. 학습 방식을 고릅니다. 카드 뒤집기, 객관식 퀴즈, 주관식 중에서 선택합니다.
  3. 방향을 정합니다. 단어 → 뜻, 뜻 → 단어, 문제마다 무작위 중에서 고릅니다.
  4. 문항 수를 정하고 시작합니다.

옵션 설명

단어 → 뜻 / 뜻 → 단어 / 무작위
한 방향만 연습하면 반대로는 잘 안 나옵니다. 어느 정도 익은 뒤에는 무작위로 두는 편이 효과적입니다.
객관식 · 카드 뒤집기
객관식은 보기 4개 중에 고르고, 카드는 눌러서 뒤집습니다. 처음에는 카드로 익히고 나중에 객관식으로 확인하는 순서가 무난합니다.
랜덤 섞기 · 문항 수
순서를 외워버리는 것을 막고, 한 번에 풀 분량을 정합니다.

자주 묻는 질문

단어장을 어떻게 적나요
한 줄에 하나씩 "Apple / 사과" 형태로 적습니다. 슬래시 앞이 문제, 뒤가 정답이 됩니다.
만든 단어장이 저장되나요
브라우저 안에 남습니다. 같은 기기에서 다시 열면 그대로 있지만, 브라우저 데이터를 지우면 사라지니 중요한 목록은 따로 복사해 두세요.
엑셀에서 옮길 수 있나요
두 열을 복사해 붙인 뒤 사이를 슬래시로 바꾸면 됩니다. 스마트 리스트 포맷터로 접미사·접두사 기능을 쓰면 편합니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
