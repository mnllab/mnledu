AI에 파일 여러 개를 넣을 때 생기는 일

코드나 문서 여러 개를 한꺼번에 AI에 물어보고 싶은데, 파일을 하나씩 올리면 어떤 내용이 어느 파일인지 구분이 흐려집니다. 그냥 이어 붙이면 경계가 사라져서 AI가 엉뚱한 파일 얘기를 하기도 합니다.

이 도구는 파일마다 이름을 붙이고 코드펜스나 구분선으로 경계를 명확히 표시해 하나의 프롬프트로 합칩니다. 전체 글자 수와 대략적인 토큰 수도 함께 보여줘서, 모델의 입력 한도를 넘는지 미리 가늠할 수 있습니다.

이럴 때 씁니다

코드 리뷰 요청
여러 파일에 걸친 기능을 한 번에 검토받을 때. 파일 경계가 명확해야 AI가 정확히 짚습니다.
문서 여러 편 요약
회의록이나 보고서 여러 개를 넘겨 공통점과 차이를 정리해 달라고 할 때.
토큰 한도 확인
넣기 전에 분량을 확인해 잘릴 위험을 줄입니다. 한도를 넘으면 파일을 나눠 두 번에 물어보는 편이 낫습니다.
자료 묶음 보관
나중에 다시 물어볼 자료를 하나의 텍스트로 만들어 두면, 매번 파일을 다시 모으지 않아도 됩니다.

사용 방법

  1. 파일을 추가합니다. 여러 개를 한꺼번에 넣을 수 있습니다.
  2. 구분 방식을 고릅니다.
  3. 병합 결과를 확인하고 프롬프트 전체 복사로 가져가 AI에 붙여넣습니다.

옵션 설명

코드펜스 형식
각 파일을 백틱 세 개로 감쌉니다. 코드를 넘길 때 적합하며, AI가 코드와 설명을 확실히 구분합니다.
구분선 형식
파일 사이를 구분선으로 나눕니다. 일반 문서를 넘길 때 읽기 편합니다.

자주 묻는 질문

표시되는 토큰 수가 정확한가요
대략적인 추정치입니다. 모델마다 토큰을 세는 방식이 달라 실제 값과 차이가 날 수 있으니, 한도에 근접할 때는 여유를 두시는 게 좋습니다.
파일이 서버로 올라가나요
아닙니다. 브라우저가 파일을 직접 읽어 화면에서 합칩니다. 외부로 전송되지 않습니다.
어떤 파일 형식을 넣을 수 있나요
텍스트로 읽히는 파일이면 됩니다. 코드 파일, txt, md, csv 등이 해당합니다. 워드나 PDF처럼 압축된 형식은 텍스트로 변환한 뒤 넣으셔야 합니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
