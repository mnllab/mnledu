🎙 고정밀 AI 재인식 선택

실시간 받아쓰기는 현재 Web Speech를 그대로 사용합니다. 필요할 때만 Whisper-base q8이 마지막 녹음 구간을 브라우저 안에서 다시 듣고 텍스트를 교체합니다. 생성형 언어모델은 사용하지 않습니다.

저부하 q8/WASM 경로를 별도 Worker에서 실행합니다. 재인식은 마지막 녹음의 최근 최대 3분만 처리합니다.

이 도구 공유하기

























말로 적는 게 빠를 때가 있다


아이디어가 떠올랐을 때, 이동 중일 때, 타자보다 말이 빠를 때가 있습니다. 그런데 받아쓰기 서비스는 대개 음성을 서버로 보내 처리합니다. 회의 내용이나 상담 기록처럼 밖으로 나가면 곤란한 이야기라면 쓰기가 망설여집니다.


이 도구는 음성 인식 모델을 브라우저에 내려받아 기기 안에서 처리합니다. 처음 한 번 모델을 설치하면 그 뒤로는 음성이 외부로 나가지 않습니다.


이럴 때 씁니다


회의 메모
회의 중 요점을 말로 남길 때. 내용이 서버로 가지 않아 부담이 적습니다.


이동 중 아이디어 기록
손으로 타자를 치기 어려운 상황에서 떠오른 것을 바로 남길 때.


긴 글 초안
말로 먼저 쏟아낸 뒤 글로 다듬는 방식. 백지 앞에서 막힐 때 효과가 있습니다.


용어가 많은 분야
자주 틀리는 단어를 교정 목록에 등록해 두면 인식할 때마다 자동으로 고쳐집니다.




사용 방법
    

  1. 처음이라면 모델 설치를 눌러 음성 인식 모델을 내려받습니다. 한 번만 하면 됩니다.
    2. 

  2. 마이크 버튼을 누르고 말합니다. 직접 타이핑해서 섞어 쓸 수도 있습니다.
    3. 

  3. 자주 틀리는 단어는 교정 목록에 잘못된말 → 고칠말 형태로 등록합니다.
    4. 

  4. 전체 다듬기로 정리한 뒤 복사해 갑니다.
    5. 



옵션 설명


정확도 · 엄격 / 보통 / 느슨
인식을 얼마나 신중하게 할지 정합니다. 엄격은 정확하지만 느리고, 느슨은 빠르지만 오인식이 늘어납니다.


인식 언어
한국어 등 인식할 언어를 지정합니다. 언어를 맞춰두면 정확도가 올라갑니다.


한 문단으로
끊어 말한 내용을 하나의 문단으로 이어 붙입니다.


교정 목록
고유명사나 전문 용어처럼 자주 틀리는 단어를 등록해 둡니다. 브라우저에 저장되어 다음에도 적용됩니다.




자주 묻는 질문


음성이 서버로 전송되나요
아닙니다. 모델을 기기에 내려받아 브라우저 안에서 인식합니다. 처음 모델을 받을 때만 통신이 필요하고, 그 뒤에는 음성이 외부로 나가지 않습니다.


모델 설치에 시간이 걸리나요
용량이 있는 편이라 네트워크 상태에 따라 몇 분 걸릴 수 있습니다. 한 번 받으면 브라우저에 남아 다음부터는 바로 시작됩니다.


인식이 잘 안 될 때는
정확도를 엄격으로 올리고, 마이크와 가까이서 또박또박 말해 보세요. 특정 단어가 계속 틀린다면 교정 목록에 등록하시는 편이 확실합니다.




이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
