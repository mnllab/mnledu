이 도구 공유하기

  • 이 도구는 아직 버전 기록이 없습니다.

명단 형식이 제각각이라 매번 다시 다듬는 문제

어떤 명단은 엑셀에서 오고, 어떤 건 한글 문서의 대괄호 목록이고, 어떤 건 마크다운 표입니다. 문장 틀은 같은데 데이터 형식이 달라서 매번 손으로 정리하게 됩니다.

이 도구는 어느 형태로 넣어도 받아들입니다. 붙여넣은 데이터의 구조를 알아서 파악하고, 준비한 문장 틀에 끼워 여러 건을 한 번에 만들어 냅니다.

이럴 때 씁니다

공문·안내문 다건 작성
수신처만 다른 공문을 여러 장 만들 때. 기관명과 담당자만 바꿔 끼우면 됩니다.
평가 의견서 초안
심사 대상마다 항목은 같고 내용만 다른 문서. 틀을 잡아두고 데이터를 넣는 방식이 훨씬 빠릅니다.
제품 설명 문구 대량 생성
쇼핑몰 상품 설명처럼 같은 구조에 모델명과 사양만 바뀌는 문구.
SQL·설정 파일 만들기
반복되는 코드 줄에 값만 바뀌는 경우. 문장 틀에 변수를 넣어 여러 줄을 한 번에 뽑을 수 있습니다.

사용 방법

  1. 데이터를 붙여넣습니다. 대괄호 리스트, 엑셀 표, 마크다운 표 중 무엇이든 됩니다.
  2. 문장 틀을 작성합니다. 변수 칩을 눌러 넣거나 {변수명} 형태로 직접 적습니다.
  3. 결과가 바로 만들어집니다. 전체 결과 복사로 가져갑니다.

옵션 설명

결과 구분 방식
건과 건 사이를 줄바꿈만으로 나눌지, 빈 줄로 나눌지, 구분선을 넣을지 고릅니다. 문서에 붙일 때는 빈 줄, 코드로 쓸 때는 줄바꿈만이 편합니다.
복사 형식
워드·한글용과 메모장용 중에 고릅니다. 워드·한글용은 서식이 유지되고, 메모장용은 순수 텍스트로 나갑니다.

자주 묻는 질문

아닙니다. 대괄호 목록, 엑셀에서 복사한 표, 마크다운 표를 모두 인식합니다. 첫 줄이 항목 이름이면 그것을 변수명으로 씁니다.
변수 이름은 한글도 되나요
됩니다. {회사명} {담당자}처럼 한글로 적으시면 됩니다.

이메일 생성기는 제목과 본문이 나뉜 메일 전용이고 조사 자동 교정이 들어갑니다. 이 도구는 형식을 가리지 않는 범용 문장 생성기입니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
