목록 정리에 드는 시간

명단이나 항목 목록을 받아 보면 앞뒤에 공백이 붙어 있고, 중복이 섞여 있고, 순서도 뒤죽박죽인 경우가 많습니다. 여기에 번호를 매기거나 쉼표로 이어 붙이는 작업까지 하려면 엑셀을 열어 함수를 쓰게 됩니다.

이 도구는 그 과정을 한 화면에서 처리합니다. 줄바꿈으로 나뉜 목록을 붙여넣고 필요한 항목만 켜면 됩니다.

이럴 때 씁니다

참가자 명단 정리
여러 경로로 받은 명단을 합쳤을 때 중복을 걸러내고 가나다순으로 맞출 때.
번호 붙은 목록 만들기
보고서에 넣을 항목에 1. 2. 3. 또는 ①②③을 붙일 때.
쉼표로 이어 붙이기
이메일 주소 목록을 한 줄로 합쳐 수신자 칸에 넣을 때. 구분자를 지정할 수 있습니다.
접두사·접미사 일괄 적용
모든 항목 앞에 경로를 붙이거나 뒤에 확장자를 붙일 때. 코드 작업이나 파일 목록 정리에 씁니다.

사용 방법

  1. 왼쪽에 목록을 붙여넣습니다. 한 줄에 한 항목입니다.
  2. 필요한 옵션을 켭니다. 여러 개를 동시에 적용할 수 있습니다.
  3. 오른쪽 결과를 확인하고 결과 복사로 가져갑니다.

옵션 설명

중복 제거 · 빈 줄 제거 · 양쪽 공백 제거
목록을 다듬는 기본 정리입니다. 여러 곳에서 모은 자료를 합쳤을 때 먼저 켜두면 좋습니다.
오름차순 정렬
가나다순 또는 알파벳순으로 맞춥니다.
번호 매기기 · 번호 형식
항목마다 번호를 붙입니다. 형식은 여러 가지 중에서 고를 수 있습니다.
한 줄로 합치기 · 구분자
전체를 한 줄로 만듭니다. 구분자에 쉼표나 세미콜론을 지정하면 그것으로 이어집니다.
접두사 · 접미사
모든 항목의 앞뒤에 같은 문자열을 붙입니다.

자주 묻는 질문

정리(공백·중복·빈 줄) → 정렬 → 접두사·접미사 → 번호 → 합치기 순으로 처리됩니다. 결과를 보면서 조절하시면 됩니다.
원본이 바뀌나요
아닙니다. 왼쪽 원본은 그대로 두고 오른쪽에 결과만 새로 만듭니다. 옵션을 껐다 켜며 여러 결과를 비교할 수 있습니다.
