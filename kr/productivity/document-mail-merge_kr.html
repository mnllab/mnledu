템플릿 문서 일괄 생성기

문서의 {{항목}}을 자동 감지하고 Excel·CSV 데이터로 여러 문서를 한 번에 생성합니다.

✓ HWPX·DOCX 원본 서식 유지 ✓ Excel·CSV 일괄 생성 ✓ 서버 업로드 없음

1. 문서 템플릿

직접 입력하거나 TXT·MD·DOCX·HWPX 파일을 불러오세요

TXT · MD · DOCX · HWPX 파일을 여기로 끌어다 놓아도 됩니다
템플릿을 입력해 주세요

2. 항목과 데이터

고유 항목은 최대 20개까지 사용할 수 있습니다

0 / 20

데이터 입력 방식

Excel / CSV 일괄 데이터

첫 행 = 항목명, 두 번째 행 = 미리보기 예시, 이후 모든 행 = 일괄 생성

Excel · CSV 파일을 여기로 끌어다 놓아도 됩니다
일괄 데이터 없음 · 현재는 직접 입력 모드

3. 결과 미리보기 및 내보내기

직접 입력 예시

같은 문서 100장, 이름만 다른 그 반복 작업

초대장, 안내문, 계약서처럼 이름·날짜·금액만 바뀌고 나머지는 똑같은 문서를 여러 건 만들어야 할 때가 있습니다. 하나씩 복사해서 고치다 보면 어딘가 하나는 꼭 빠뜨리거나 잘못 고치게 됩니다.

이 도구는 문서 안의 {{이름}}, {{날짜}} 같은 항목을 자동으로 찾아내고, 엑셀·CSV 한 줄당 문서 하나씩 만들어 ZIP으로 묶어 줍니다. DOCX·HWPX는 원본 서식을 그대로 유지한 채로요.

이럴 때 씁니다

초대장·안내문 대량 발송
참석자 명단 엑셀 하나로 이름이 다 다른 초대장 수십 장을 한 번에 만들 때.
계약서·확인서 일괄 생성
거래처명·금액만 다른 계약서를 원본 서식 그대로 여러 건 뽑을 때.
DOCX·HWPX 서식 유지
이미 만들어 둔 양식 파일의 글꼴·표·머리글을 그대로 두고 내용만 바꿀 때.
여러 형식으로 뽑기
같은 템플릿을 HWPX·DOCX·TXT·MD 중 필요한 형식으로 내보낼 때.

사용 방법

  1. 문서 템플릿을 직접 입력하거나 TXT·MD·DOCX·HWPX 파일을 불러옵니다.
  2. 문서 안에 {{이름}}, {{날짜}}처럼 바뀔 항목을 표시합니다 (최대 20개).
  3. 한 건이면 직접 입력, 여러 건이면 Excel·CSV를 불러와 내보냅니다.

옵션 설명

DOCX·HWPX 원본 서식 유지
DOCX 템플릿은 DOCX로, HWPX 템플릿은 HWPX로 내보낼 때 원본 파일의 글꼴·표·이미지·머리글까지 그대로 유지합니다. 템플릿 텍스트를 직접 고치면 이 모드는 자동으로 해제됩니다.
{{번호}} 자동 증가
001, 002, 003처럼 자동으로 순번이 매겨지는 예약 항목입니다.
파일명 규칙
{{이름}} 같은 항목을 파일명에도 쓸 수 있어, 결과 ZIP 안에서 바로 구분됩니다.

자주 묻는 질문

데이터가 서버로 전송되나요
아닙니다. 템플릿 읽기, Excel/CSV 파싱, 항목 치환, 문서 생성과 ZIP 묶기까지 전부 브라우저 안에서 처리합니다.
Excel 열 이름은 템플릿 항목과 똑같아야 하나요
네. 템플릿의 {{이름}}은 Excel 첫 행의 "이름" 열과 정확히 일치해야 연결됩니다.
DOCX 파일을 HWPX로 내보내면 서식이 유지되나요
아닙니다. 원본 서식 유지는 같은 형식으로 내보낼 때만 적용됩니다(DOCX→DOCX, HWPX→HWPX). 다른 형식으로 바꾸면 화면에서 지정한 공통 서식으로 새로 생성됩니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
