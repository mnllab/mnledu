PDF 합치기에 프로그램이 필요할까

신청 서류를 제출할 때 증빙 자료 여러 장을 하나의 PDF로 묶어야 하는 경우가 많습니다. 반대로 긴 보고서에서 필요한 몇 쪽만 떼어내야 할 때도 있습니다.

이런 작업 때문에 유료 프로그램을 설치하거나, 파일을 모르는 웹사이트에 업로드하게 됩니다. 제출용 서류에는 계좌번호나 사업자등록증처럼 민감한 내용이 들어 있는데도요. 이 도구는 브라우저 안에서 처리하므로 파일이 밖으로 나가지 않습니다.

이럴 때 씁니다

제출 서류 묶기
사업자등록증, 통장 사본, 각종 증명서를 하나의 PDF로 합쳐 제출할 때.
필요한 쪽만 추출
수십 쪽짜리 보고서에서 특정 장만 떼어 공유할 때.
스캔 순서 정리
양면 스캔을 했더니 홀수쪽과 짝수쪽이 따로 나온 경우. 홀수쪽·짝수쪽 버튼으로 나눠 처리할 수 있습니다.
용량 큰 파일 나누기
메일 첨부 한도를 넘는 PDF를 앞뒤 절반으로 나눠 보낼 때.

사용 방법

  1. 파일을 끌어다 놓거나 클릭해서 선택합니다. 여러 개를 한꺼번에 넣을 수 있습니다.
  2. 합칠 것인지 추출할 것인지 정합니다.
  3. 추출이라면 1-3, 5, 7-10처럼 쪽 범위를 적습니다.
  4. 병합 및 다운로드 또는 추출 및 다운로드를 누릅니다.

옵션 설명

전체 · 홀수쪽 · 짝수쪽
자주 쓰는 범위를 버튼 하나로 지정합니다. 양면 스캔 정리에 편합니다.
앞 절반 · 뒤 절반
전체를 반으로 나눕니다. 용량 때문에 분할할 때 씁니다.
범위마다 파일 나눠 저장
여러 범위를 적었을 때 하나로 합칠지, 범위별로 따로 저장할지 고릅니다.

자주 묻는 질문

파일이 어디로 전송되나요
전송되지 않습니다. 브라우저가 파일을 직접 읽어 처리하고 결과를 바로 내려받게 합니다. 제출용 서류처럼 민감한 자료를 다룰 때 이 점이 중요합니다.
암호가 걸린 PDF도 되나요
열람 암호가 걸린 파일은 처리할 수 없습니다. 암호를 푼 뒤 사용해 주세요.
쪽 범위는 어떻게 적나요
쉼표로 나누고 하이픈으로 범위를 표시합니다. 예를 들어 1-3, 5, 7-10 은 1·2·3·5·7·8·9·10쪽을 뜻합니다.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
