아직 표 데이터가 없어요

왼쪽에 텍스트를 붙여넣거나 엑셀 파일을 올려보세요.

엑셀에서 표를 복사해 한글(HWP) 문서에 붙여넣으면 서식이 깨지고, 반대로 한글 표를 엑셀로 옮기려면 한 칸씩 다시 입력해야 했던 경험, 다들 있으실 거예요. 보고서 하나 만드는 데 표 포맷 맞추는 시간이 본문 쓰는 시간보다 길어질 때도 있고요. 만능 표 데이터 허브는 메모장에 붙여넣은 텍스트나 엑셀 파일을 표로 자동 인식해서, 원하는 서식을 입힌 뒤 HWPX·DOCX·XLSX 등 필요한 형식으로 바로 내보내 주는 도구입니다.

왜 붙여넣기 방식과 파일 업로드를 함께 지원하나요

회의 중 급하게 표를 옮겨야 할 때는 엑셀 파일을 열 필요 없이 셀 범위를 복사해 텍스트로 붙여넣는 쪽이 훨씬 빠릅니다. 반면 이미 정리된 엑셀 파일이 있다면 파일째로 올리는 게 편하죠. 두 입력 방식 모두 같은 2차원 배열 구조로 변환되기 때문에, 어느 쪽으로 넣든 이후 서식 설정과 내보내기 과정은 동일하게 동작합니다.

구분자를 어떻게 자동으로 알아내나요

붙여넣은 텍스트에 | 이름 | 나이 | 형태와 |---|---| 구분선이 함께 있으면 마크다운 표로 판단하고, 탭 문자가 있으면 엑셀에서 복사한 TSV로, 쉼표만 있으면 CSV로 처리합니다. 우선순위를 마크다운 > TSV > CSV 순으로 둔 이유는 마크다운 표 문법 안에도 쉼표가 자주 섞여 있어서, 쉼표를 먼저 기준으로 삼으면 표가 깨지기 때문입니다. 구분자가 전혀 없는 텍스트는 한 줄을 1열짜리 행 하나로 처리해 데이터가 사라지지 않도록 했습니다.

'글자처럼 취급'과 전체 너비는 왜 따로 뒀나요

한글(HWP)에서 표를 개체로 두면 본문 흐름과 무관하게 떠 있다가 문단이 늘어나면 겹쳐 보이는 문제가 흔합니다. 그래서 기본값을 '글자처럼 취급' 켜짐으로 두어 본문 글자와 같은 흐름에 붙게 했고, 대신 표 폭을 mm 단위로 직접 지정할 수 있게 해 A4 기준 좌우 여백을 뺀 폭(약 160mm)에 맞추기 쉽도록 했습니다.

내보내기 형식은 어떤 기준으로 골랐나요

HWPX는 한글 문서에 바로 넣을 목적, DOCX는 MS 워드·구글 문서 공유 목적, XLSX는 재가공 목적, MD·CSV는 개발 문서나 데이터 이관 목적으로 각각 씁니다. '한글 최적화 클립보드 복사'는 파일을 만들지 않고 바로 Ctrl+V로 붙여넣고 싶을 때를 위한 것으로, 인라인 CSS가 포함된 HTML 표를 클립보드에 담아 셀 테두리와 정렬이 그대로 유지되도록 했습니다.

붙여넣은 표 데이터가 서버로 전송되나요?
아니요. 모든 파싱과 파일 생성은 브라우저 안에서만 이루어지며, 어떤 데이터도 외부 서버로 전송되지 않습니다.
엑셀 파일을 업로드하면 원본 파일이 서버에 저장되나요?
저장되지 않습니다. SheetJS 라이브러리가 브라우저 메모리에서만 파일을 읽고, 창을 닫으면 데이터는 남지 않습니다.
표 구분자를 직접 선택해야 하나요?
아니요. 탭(TSV), 쉼표(CSV), 마크다운 표 문법을 자동으로 감지합니다. 다만 감지가 애매한 경우 상단에서 구분자를 수동으로 지정할 수 있습니다.
HWPX로 내보낸 파일이 실제 한글(한컴오피스)에서 열리나요?
한글 OWPML 표준 구조를 따라 생성하며 한컴오피스 2020 이상에서 열리도록 설계했습니다. 다만 매우 복잡한 서식(중첩 표, 특수 개체 등)은 지원하지 않습니다.
'글자처럼 취급' 옵션은 무엇인가요?
한글(HWP)에서 표를 본문 글자와 같은 흐름으로 배치할지, 자유롭게 배치되는 개체로 둘지를 정하는 옵션입니다. 문서 편집 중 표가 밀리지 않게 하려면 켜 두는 것을 권장합니다.
몇 행, 몇 열까지 처리할 수 있나요?
브라우저 메모리 한도 내에서 수천 행 단위까지 실시간 처리를 확인했습니다. 매우 큰 데이터는 미리보기가 일부만 표시될 수 있습니다.

이 도구는 서버로 어떤 데이터도 전송하지 않는 100% 브라우저 실행 방식입니다. 입력한 표 데이터, 업로드한 엑셀 파일은 저장되지 않으며 창을 닫으면 사라집니다. 민감한 사내 데이터를 다루더라도 외부로 유출될 걱정 없이 사용하실 수 있습니다.

엑셀 표와 한글 문서 사이, 매번 깨지는 서식

엑셀에서 복사한 표를 한글(HWP) 문서에 붙여넣으면 서식이 깨지고, 반대로 한글 표를 엑셀로 옮기려면 한 칸씩 다시 입력해야 했던 경험이 있으실 겁니다. 보고서 하나 만드는 데 표 포맷 맞추는 시간이 본문 쓰는 시간보다 길어질 때도 있습니다.

이 도구는 메모장에 붙여넣은 텍스트나 엑셀 파일을 표로 자동 인식해서, 원하는 서식을 입힌 뒤 HWPX·DOCX·XLSX 등 필요한 형식으로 바로 내보냅니다.

회의 중 급한 표 정리
엑셀 파일을 열 필요 없이 셀 범위를 복사해 텍스트로 붙여넣어 바로 표로 만들 때.
엑셀 파일을 한글 문서로
이미 정리된 엑셀 파일을 그대로 올려 HWPX·DOCX로 내보낼 때.
한글 최적화 서식 적용
글자처럼 취급, 줄 간격, 전체 너비 같은 한글(HWP) 특유의 옵션을 맞춰서 내보낼 때.
여러 형식으로 동시에 활용
같은 표를 상황에 따라 HWPX·DOCX·XLSX·MD·CSV 중 필요한 형식으로 바꿔 쓸 때.

사용 방법

  1. 메모장에서 표를 붙여넣거나 엑셀 파일(.xlsx, .csv)을 끌어다 놓습니다.
  2. 왼쪽 서식 제어판에서 정렬·글자 크기·줄 간격·너비 등을 정합니다.
  3. 오른쪽 미리보기로 확인한 뒤 원하는 형식으로 내보냅니다.

자주 묻는 질문

붙여넣기와 파일 업로드를 둘 다 지원하는 이유는 무엇인가요
급하게 표를 옮겨야 할 때는 셀 범위를 복사해 텍스트로 붙여넣는 쪽이 빠르고, 이미 정리된 파일이 있다면 통째로 올리는 게 편합니다. 두 방식 모두 같은 표 구조로 변환되므로 어느 쪽을 쓰든 결과는 동일합니다.
표 데이터가 서버로 전송되나요
아닙니다. 붙여넣은 텍스트와 업로드한 파일 모두 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
HWPX로 내보내면 한글에서 바로 열리나요
네. 한글(HWP) 프로그램에서 여는 것을 기준으로 서식을 맞췄습니다. 정렬이 어긋나면 서식 제어판에서 값을 조정한 뒤 다시 내보내 보세요.

이 도구는 사용자의 브라우저 안에서만 동작합니다. 입력한 내용은 서버로 전송되지 않으며 어디에도 저장되지 않습니다. 페이지를 닫으면 처리 중이던 내용도 함께 사라집니다.
