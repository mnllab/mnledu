🧠 온디바이스 AI 정밀 정리

모든 처리는 이 브라우저 탭 안에서 이뤄집니다. 페이지를 닫거나 새로고침하면 업로드한 파일과 변환 결과가 전부 사라집니다 — 서버 어디에도 보관되지 않습니다.

기밀 계약서나 사내 보고서를 Markdown으로 바꿔야 하는데, 온라인 변환기에 올리자니 정보 유출이 마음에 걸리고, 손으로 다시 치자니 표와 캡션이 계속 어긋납니다. 이 변환기는 정확히 그 틈을 메우려고 만들었습니다. 파일은 브라우저를 벗어나지 않고, 문장 중간에 끊긴 줄바꿈과 모든 페이지에 반복되는 머리글도 자동으로 정리됩니다.

서버 업로드가 없는 이유

PDF.js는 브라우저 안에서 PDF를 파싱하는 라이브러리라, FileReader로 파일을 메모리에 읽어 텍스트 좌표를 뽑아내는 순간 변환이 끝납니다 — 서버가 끼어들 지점이 애초에 없습니다. 계약서나 인사 자료처럼 밖으로 나가면 안 되는 문서를 다루는 도구라면, 전송 경로 자체를 만들지 않는 게 가장 확실한 보안입니다.

표를 감지하는 방법 — 좌표 간격 기반 추정

PDF 안의 모든 텍스트 조각은 저마다 x/y 좌표를 갖습니다. 같은 y값(줄)에서 다음 조각까지의 간격이 평균 글자 너비의 3.2배를 넘으면 그 간격을 열 경계로 봅니다. 다만 넓은 간격 하나만으로 표라고 단정하면 오탐이 너무 많아지므로, 연속된 두 줄 이상이 ±1 오차 안에서 같은 열 개수를 반복할 때만 표로 승격시켜 Markdown 표 문법으로 재구성합니다. 열이 하나뿐이거나 다음 줄의 열 구성이 완전히 다르면 일반 문단으로 처리합니다.

끊어진 줄바꿈을 찾아내는 방법

PDF는 페이지 너비에 맞추려고 강제로 줄을 바꾸므로, 마침표·물음표·닫는 괄호 같은 문장 종결 부호로 끝나지 않는 줄은 다음 줄과 이어 붙입니다. 예외는 다음 줄이 새 목록 항목(-, 1.)으로 시작하거나 캡션·표의 한 행인 경우입니다 — 이런 줄은 건드리지 않습니다. 그렇지 않으면 목록이 한 줄로 뭉개지거나, 표 주변 문장이 표 안으로 섞여 들어갈 수 있습니다.

반복되는 머리글·바닥글을 지우는 방법

전체 페이지의 60% 이상에서 토씨 하나 안 틀리고 등장하는 짧은 줄(80자 이하)은 회사명·문서 제목·"기밀" 표시 같은 반복 머리글로 보고 자동으로 지웁니다. 쪽 번호 패턴(3, Page 3 of 10 등)은 별도로 걸러냅니다. 3페이지 미만 문서는 반복 여부를 판단할 표본이 부족하므로 이 로직 자체를 건너뜁니다 — 그렇지 않으면 2페이지짜리 문서에서 우연히 겹친 문장이 머리글로 오인돼 지워질 수 있습니다.

온디바이스 AI가 30~80MB 모델을 고수하는 이유

1GB가 넘는 생성형 LLM을 브라우저에 올리면 저사양 노트북에서는 탭이 멈추거나 죽습니다. 그래서 이 도구는 텍스트 교정과 서식 정리에 맞춰진 경량 모델을 씁니다. 양자화하면 약 80MB인 Xenova/flan-t5-small입니다. 이마저도 메인 스레드에서 돌리면 화면이 멈추기 때문에, 모델 로드와 텍스트 생성 모두 Web Worker 안에서 처리하고, 문단 단위로 잘라 하나씩 보내며 진행률로 진행 상황을 표시합니다. 표와 캡션 자리표시자는 AI 처리 대상에서 완전히 제외해서, 모델이 Markdown 문법 자체를 망가뜨릴 수 없게 했습니다.

그림·표 캡션을 보존하는 방법

"Figure 1.", "Table 2.", "Fig. 3:"처럼 그림 번호로 시작하는 줄을 발견하면, 실제 이미지는 추출하지 않고 대신 [🖼️ 이미지 생략: Figure 1. System architecture] 같은 자리표시자로 바꿔 둡니다. 그러면 이미지가 있었다는 사실과 무엇에 대한 것이었는지가 Markdown만 읽어도 그대로 전달됩니다.

자주 묻는 질문

업로드한 PDF가 외부 서버로 전송되나요?
아닙니다. 업로드부터 변환까지 전부 브라우저 안에서 이뤄집니다. 파일을 선택하는 순간에도 네트워크 요청이 발생하지 않으며, 페이지를 새로고침하면 메모리에 있던 데이터도 사라집니다.
온디바이스 AI 정밀 정리를 켜면 무엇이 달라지나요?
경량 로컬 AI 모델이 PDF.js가 이미 뽑아낸 텍스트를 다시 살펴보고 어색한 줄바꿈과 표 서식을 다듬습니다. 기본 모드만으로도 충분히 쓸 만하며, AI 모드는 결과를 한 번 더 다듬고 싶을 때 쓰는 선택 사항입니다.
AI 모델을 매번 다시 내려받나요?
아닙니다. 처음 한 번만 내려받아 브라우저 캐시에 저장되고, 그 이후로는 다시 받지 않고 즉시 불러옵니다. 브라우저 저장공간을 지우면 한 번 더 받아야 합니다.
PDF 안의 표가 정확하게 변환되나요?
열 사이의 간격을 분석하는 좌표 기반 방식으로 표를 감지해 Markdown 표로 재구성합니다. 셀 병합이 많거나 배경 이미지로 그려진 표는 완벽하게 인식되지 않을 수 있으니, 변환 후 편집기에서 결과를 한 번 확인해 보시는 걸 권합니다.
스캔한(이미지로만 된) PDF도 지원하나요?
이미지로만 된 스캔 PDF는 이 도구의 범위 밖입니다. PDF 안에 이미 존재하는 텍스트 레이어를 읽는 방식이라, 선택 가능한 텍스트가 없는 스캔본은 빈 결과가 나옵니다.
결과에서 표가 어긋나게 나오면 어떻게 하나요?
왼쪽의 '표 자동 인식' 옵션을 끄면 표를 일반 텍스트로 받아 직접 정리할 수 있습니다. 그래도 안 맞으면 오른쪽 편집기에서 Markdown을 직접 고치시면 됩니다.

이 도구는 PDF를 서버로 절대 보내지 않습니다. 모든 텍스트 추출과 변환은 브라우저 안에서만 이뤄지며, 페이지를 새로고침하거나 닫으면 업로드한 내용과 변환 결과가 모두 사라집니다(직접 저장해 두지 않으면 복구할 방법이 없습니다). 온디바이스 AI 모드를 켜면 약 80MB짜리 모델 파일을 브라우저 캐시에 한 번 내려받으며, 이때 인터넷 연결이 필요합니다.
