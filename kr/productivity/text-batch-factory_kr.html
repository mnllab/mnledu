03 / OUTPUT

가공 결과

입력창과 결과창의 스크롤은 함께 움직입니다.

텍스트를 붙여 넣고, 필요한 규칙만 켜면 됩니다

이 도구는 웹에서 복사한 문서, 회의 메모, 영상 대본, 엑셀 목록처럼 형식이 뒤섞인 텍스트를 빠르게 정리하기 위한 작업 공간입니다. 입력한 텍스트는 브라우저 안에서 자바스크립트로만 가공하며 외부 API를 호출하거나 서버로 전송하지 않습니다.

왼쪽에는 원문을 그대로 넣고, 가운데에서는 필요한 기능만 조합합니다. 오른쪽 결과는 입력이나 옵션 변경과 동시에 다시 계산되므로 별도 실행 버튼을 누를 필요가 없습니다.

클리너는 중복해서 조합할 수 있습니다

마크다운 기호 싹쓸이는 제목의 #, 강조의 **, 링크의 [텍스트](주소), 인용표시 같은 문법을 제거하고 읽을 수 있는 문장만 남깁니다. 링크는 주소 대신 링크 이름을 남기도록 처리합니다.

뭉친 리스트 복원은 한 문장 안에 붙은 1., 2., -, • 앞을 찾아 새 줄로 나눕니다. 마지막으로 공백 정리를 켜면 각 줄의 앞뒤 공백과 여러 개 연속된 빈 줄을 정리합니다.

자막 분할은 단어를 보존합니다

자막 모드를 켜고 한 줄 최대 글자 수를 10자에서 40자 사이로 정하면, 띄어쓰기를 기준으로 가능한 범위에서 줄을 나눕니다. 긴 단어 하나는 임의로 반으로 자르지 않고 한 줄에 유지합니다.

두 줄 자막 묶기를 켜면 나뉜 자막 두 줄 사이에는 줄바꿈을 유지하고, 다음 자막 묶음과는 빈 줄로 구분합니다. 자막 편집기에 바로 붙여 넣기 좋은 형태입니다.

리스트·엑셀 가공은 줄 단위로 처리합니다

숫자 넘버링 또는 사용자 불릿을 선택하면 빈 줄을 제외한 모든 줄 앞에 접두어를 붙입니다. 중복 제거는 글자가 완전히 같은 줄만 하나로 남기므로 비슷하지만 다른 데이터는 안전하게 유지합니다.

URL / 이메일만 추출을 켜면 현재 텍스트 안에서 웹 주소와 이메일을 찾아 한 줄에 하나씩 결과로 만듭니다. 메일링 목록이나 참고 링크만 따로 모을 때 유용합니다.

자주 묻는 질문

텍스트가 외부로 전송되나요?
아니요. 가공 규칙과 정규식은 모두 현재 브라우저에서 실행됩니다. 네트워크 요청, API 호출, 계정 로그인 기능이 없습니다.
긴 텍스트도 사용할 수 있나요?
가능합니다. 입력이 매우 길 때에도 매 키 입력마다 즉시 여러 번 실행하지 않도록 짧게 묶어 처리합니다. 다만 수십만 자 이상의 텍스트는 브라우저와 기기 성능에 따라 잠시 시간이 걸릴 수 있습니다.
원본과 결과를 함께 비교할 수 있나요?
좌측과 우측 텍스트 영역은 스크롤 위치를 비율로 동기화합니다. 결과의 줄 수가 달라도 같은 진행 위치를 보며 비교할 수 있습니다.
가공 결과를 다시 편집할 수 있나요?
결과창은 의도치 않은 덮어쓰기를 막기 위해 읽기 전용입니다. 필요한 결과를 복사한 뒤 원하는 편집기나 문서에 붙여 넣어 마무리하세요.

이 앱의 모든 텍스트 가공은 로컬 브라우저에서 이루어집니다. Tailwind CSS CDN은 화면 스타일을 불러오는 데에만 사용되며, 입력한 텍스트의 처리·분석·저장은 별도 서버를 거치지 않습니다.

형식이 뒤섞인 텍스트를 정리하는 일

웹에서 복사한 글, 회의 메모, 영상 대본, 엑셀 목록은 저마다 다른 습관으로 만들어져 있습니다. 마크다운 기호가 섞여 있거나, 리스트가 한 문장으로 뭉쳐 있거나, 빈 줄이 들쭉날쭉합니다.

이 도구는 그 정리 규칙들을 조합해서 씁니다. 왼쪽에 원본을 붙이고 필요한 규칙만 켜면 오른쪽에 정리된 결과가 바로 나옵니다.

이럴 때 씁니다

마크다운 문서를 일반 텍스트로
#, **, [링크](주소) 같은 문법을 지우고 읽을 수 있는 문장만 남길 때.
자막 원고 만들기
긴 대본을 한 줄 글자 수 제한에 맞춰 자막 편집기에 바로 붙일 수 있는 형태로 나눌 때.
엑셀·리스트 가공
번호나 불릿을 붙이거나, 중복된 줄을 지우거나, 링크·이메일만 뽑아낼 때.
복사한 글의 잔여 서식 제거
여러 곳에서 모은 글을 합칠 때 빈 줄과 공백을 정리해 깔끔하게 맞출 때.

사용 방법

  1. 원본 텍스트를 왼쪽에 붙여넣습니다.
  2. 필요한 정리 규칙을 켭니다. 여러 개를 함께 켤 수 있습니다.
  3. 오른쪽 결과를 복사해 갑니다.

엑셀 / 리스트 가공
번호·불릿 추가, 중복 제거, URL·이메일만 추출 중 골라 씁니다.
