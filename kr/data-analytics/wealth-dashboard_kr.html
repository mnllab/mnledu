이 도구 공유하기

복리와 물타기, 감으로 계산하다 틀리는 두 가지

"20년 뒤에 얼마가 될까"는 매월 적립액에 기간을 곱하는 걸로는 안 나옵니다. 복리는 뒤로 갈수록 붙는 속도가 빨라지는데, 이걸 손으로 따라가긴 어렵습니다. 물타기도 마찬가지로, 평단가를 낮췄다고 안심했다가 정작 본전까지 몇 % 남았는지는 계산 안 해보고 넘어가는 경우가 많습니다.

이 도구는 두 계산을 한 화면에서 즉시 보여줍니다. 숫자를 넣는 순간 그래프와 결과가 바로 바뀌고, 버튼을 누를 필요가 없습니다.

이럴 때 씁니다

은퇴 계획 시뮬레이션
지금 적립액으로 몇 년 뒤 얼마가 되는지, 물가를 감안하면 실제 가치는 얼마인지 미리 그려볼 때.
적립 금액 조정
월 적립액을 얼마나 늘려야 목표 기간을 앞당길 수 있는지 슬라이더처럼 숫자를 바꿔가며 확인할 때.
물타기 여부 판단
추가 매수를 하면 평단가가 얼마로 내려가는지, 본전까지 몇 % 올라야 하는지 미리 계산해 보고 결정할 때.
매도 목표가 설정
원하는 수익률을 얻으려면 얼마에 팔아야 하는지 표로 한눈에 볼 때.

사용 방법

  1. 상단에서 복리 시뮬레이터와 물타기 계산기 중 하나를 고릅니다.
  2. 왼쪽 입력창에 숫자를 넣습니다. 천 단위 콤마는 자동으로 찍힙니다.
  3. 오른쪽 그래프와 결과가 입력과 동시에 갱신됩니다.

옵션 설명

연평균 수익률·물가 상승률
기간 내내 똑같은 값이 유지된다고 가정한 단순화된 계산입니다. 실제로는 해마다 오르내리므로 참고용으로 보시는 게 안전합니다.
목표 수익률
